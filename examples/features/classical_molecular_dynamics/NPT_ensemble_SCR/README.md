# Stochastic cell-rescaling NPT example

This example demonstrates the reversible isotropic Bernetti--Bussi stochastic
cell-rescaling barostat for a classical system. It uses the bundled Python
harmonic driver so that it can be run without an external simulation package.

The required `compressibility` is an estimate of the material's isothermal
compressibility. The value in this illustrative input is representative of
liquid water near ambient conditions and should be replaced for other systems
or state points.

Run the example with:

```bash
bash run.sh
```
