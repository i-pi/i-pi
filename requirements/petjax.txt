# Known-compatible dependencies for the i-PI petjax driver, examples and tests.
#
# pet-jax pulls in jax, flax, ase, vesin and marathon-train. The
# `neighbors:jax` option of the driver (and `--jit`) needs vesin-jax (the
# `vesin-jax` extra of pet-jax), and the pet-jax that computes the neighbor
# lists with it: until it is released, that is the `vesin-jax` branch of
# pet-jax.
#
# vesin-jax 0.7 supports jax 0.10 and 0.11 (pip downgrades a newer jax). For
# a GPU, install the CUDA build of the same jax, e.g.
# `pip install "jax[cuda12]==0.11.2"`.
#
# Converting the PET-MAD checkpoints (examples/clients/petjax/getmodel.sh)
# also needs `pip install "pet-jax[convert]"` (torch, metatomic, metatrain).
jax==0.11.2
jaxlib==0.11.2
flax==0.12.12
vesin==0.6.2
vesin-jax==0.7.0rc1
pet-jax[vesin-jax] @ git+https://github.com/lab-cosmo/pet-jax@vesin-jax
